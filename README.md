# Copper Extension Wiki

## About

![icon](https://i.imgur.com/7O7v6WU.png)

This is the wiki for Copper Extension Minecraft mod. You can check the wiki [here](https://killarexe.github.io/Copper-Extension-wiki).

This wiki use hugo and hextra.

## Run/Build in local

1. Install Hugo and the Go programming language.
2. Run `hugo server` to run locally or `hugo build` to build on the result website will be on the `public` folder.
